# Handoff

Write a compact handoff so another session or agent can continue without re-deriving context. Keep
it dense and skimmable; link to the plan/spec rather than restating them.

Write it to `docs/plans/` alongside the active plan (e.g. `<plan-slug>-handoff.md`), or inline if
short. Cover:

- **Goal** — one sentence.
- **Current state** — what's done, what's in progress, what's untouched.
- **Key decisions** — each with a one-line why.
- **Next step** — the exact next action to take.
- **Open questions** — anything unresolved that blocks or shapes the next step.
- **Pointers** — relevant file paths, commands, and the plan/spec/map links.

Apply the `writing-style` skill: brief and direct, no filler.
